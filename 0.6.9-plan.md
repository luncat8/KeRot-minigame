# 0.6.9 plan — Motion-ended turns and a Staller bot (deferred)

Status: deferred; separate from the fixed-window Timing bot (0.6.8) and zone editor (0.7.0).

## Rule

only if friction > 0

Add an opt-in game mode without the strict `handoffT` turn limit: a thrown turn
continues while pucks move, then hands off when the board settles. Keep the current
fixed-window mode as the default. Define motion relative to the relevant surface:
locked riders travel with the rotating disk forever and must not make a turn infinite.
Specify whether sliding, residual spin, and a short quiet interval count before shipping.
Keep `maxThrows` as the game-length guard, not a substitute for a turn rule. Any emergency
simulation watchdog must be explicit and identical in real games, predictors and rollouts.

## Staller character

Introduce a **new `staller`**, alongside (not renamed from) `timing`. When its positioned
pucks have a higher sustained scoring rate than the strongest opponent, it seeks legal
strokes that keep motion going and extend the profitable turn. Gate the preference on
positive positional rate advantage, not merely accumulated score; when behind, prefer
improving the position rather than extending the opponent's income.

Revisit the removed `stall · lead · duration` term in `evaluateStroke` only for this mode.
Measure the incremental score from extra time using actual evolving rates (the lead can
reverse as pucks move), avoid double-counting the existing score integral, and bound the
search horizon/cost without silently imposing a new gameplay cap. The fixed-window mode
must receive no duration reward; Timing keeps its within-window red-time strategy.

## Validation / prerequisites

- Unsettled turns can exceed `handoffT`; quiet boards hand off; locked riders do not hang.
- Predictors, bots, speed-vote timing, scoring, UI timer, warp copies and embedded games
  agree on turn completion; deterministic seeded tests cover each mode.
- Paired boards: Staller extends when ahead in positional income, not when behind;
  changing only accumulated score must not flip that decision.
- Benchmark candidate duration distribution and CPU cost; retain current timing bot gates
  and fixed-mode regression results. Expose the mode through settings and preset links.
