# 0.1.7 draft — in-game rotation speed: the speed vote

User prompt for this round. It is the never-implemented last section of `0.1.0-draft.md`
("in-game rotation speed change"):

```
optional rule checkbox.

[] current behavior. set speed in settings anytime (admin mode), vote for speed and choose average (multiplayer mode)

[x] before each player turn - each player set rotation speed
		[x] increase / decrease
		[] exact desired value

[] before 1st player turn. (every N turns, where N num of players)

players can set value anytime
default is 'dont care'
values:
 [x]  dont care
 [] keep current
 ---[slider]--- +- or exact depends on settings rule

the time for value averaged and apply is 1 second after (4s) of turt timer.


i dont know what is better [x] option by default rule
```

## Reading of the prompt

- **A rule with three options**, picked in the settings panel: how the disk speed may
  change during a game.
  - *Current behaviour.* The panel slider sets the speed at any time (admin mode). In
    multiplayer the same slot would be a vote whose average applies. Multiplayer is
    not built yet (`0.1.2-plan.md`), so the vote machinery built here is what it will
    reuse.
  - *Before each player's turn.* Every seat votes, and the tally decides the speed for
    the coming turn.
  - *Before the first player's turn.* Once per round (every N turns, N = the number of
    players).
  - *A sub-option of both vote rules:* a vote is a change (+/−, ticked) or an exact
    desired speed.
- **Every seat holds one vote, settable at any time.** It is "don't care" by default.
  The choices are don't care (abstain), keep current, or a slider: a change or an
  exact speed, by the sub-option.
- **When it applies:** the votes are averaged and applied 1 second after the 4 s turn
  timer. So a vote closes in a 1 s window between two turns, and the new speed holds
  from the next throw on.
- **The default rule is open** ("I don't know what is better"). Pick it, and back the
  choice with measurement rather than taste.

Implied, and added:
- Bots vote too. A bot-only table must still use the rule, and a rule nobody exercises
  cannot be measured.
- A vote resets to don't care once it has been counted. A vote is a request for this
  tally, not a standing order, and "don't care" is the stated default.
- The disk is a motor, so a tallied change is a short ramp, not a jump. The physics
  must then charge the rider for the tangential acceleration a ramp needs, not only for
  the centripetal one. The game-over spin-down is a ramp of exactly that kind, and it
  ignores the tangential part today.
