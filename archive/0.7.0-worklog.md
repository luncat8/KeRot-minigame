## Plan corrections / implementation

- The original plan's geometry URL round-trip was impossible: none of those coordinates
  were parsed. Added shared atomic geometry validation/snapshots/derived-zone rebuilding
  in `cfg.js`, `geometry` setup/URL support, and `maxThrows` sharing. Copied JSON uses
  canonical setup keys, not URL aliases. Normal settings changes retain custom geometry;
  the default preset resets it and refits the board.
- Direct live CFG writes were not enough: armed/physical pucks retain their radius and
  inertia, scores would belong to an old board, and paths/textures are cached. The editor
  therefore resets a paused preview after each accepted edit, blocks gameplay input,
  cancels plans/queued throws, and starts a clean game on close (retaining the prior pause
  preference). Revert restores the entry setup. Reset keeps geometry like other settings.
- `main.js` owns a small retryable lazy script loader. `zone-editor.js` owns its drawer,
  overlay, controls, pointer capture and teardown; no editor frame loop or ordinary-visit
  listener/DOM overhead. The drawer is inert-isolated from the regular controls while
  editing, with numeric alternatives to all geometry handles and a selectable preset text.
- Added drags for disk/hole centres and radii, puck radius, launch position/lane edges,
  wedge/fan reach and cut-zone gap; rule/map/shape selectors plus omega, stock and throw cap.
  Pointer proposals stop at validity boundaries, numeric invalid edits give feedback,
  cancellation restores the drag start. Hole separation conservatively covers triangles
  as well as circles; launch stock cannot spawn inside a hole.
- Custom geometry freezes world dimensions against responsive refitting, while the canvas
  still resizes and the overlay tracks its actual rect. Closing/reopening removes/recreates
  the canvas, drawer, styles, window listeners and ResizeObserver. A real-browser gate
  caught and fixed the fixed-parent stacking-context bug hiding the entry button under
  the overlay on mobile.
- Renderer geometry refresh updates zone paths, puck gradients/fonts and radius-sensitive
  disk textures without rebaking the disk for every centre/launch drag. Short wedges can
  end within the disk guard: intersected triangle/outside-guard clips prevent an evenodd
  subtraction halo. Glass refreshes its board-size caches and radius-dependent soft paint.
  Score LUT retention is bounded to 16 entries so a radius drag cannot grow it unboundedly.
- Rebuilt the committed Snowfall artifact from shared sources. It gains shared geometry/
  rendering correctness but no editor UI, loader or dependency.
