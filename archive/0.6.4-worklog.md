# Field presentation and distance audio

## Review

The previous surface pass darkened the floor relative to a7f9cf6 and enabled lamp reflections unconditionally. VOID was drawn after that pass, so its paint could not look submerged. Audio used direction-only panners: distance did not change level at all.

## Changes

- Restored bakeFloorTex exactly from a7f9cf6c94330fada277229fbc11b620b60c68f8, keeping the improved disk paint scattering, glaze and etched finishes.
- Disabled lamp reflections by default; retained an explicit GlassFX.set({lamps: true}) opt-in for experiments.
- Applied stronger frozen veil and frost texture locally over RETURN and VOID paint, without tinting the restored floor globally. VOID now draws before the surface. Plain mode has no extra texture work.
- Raised right-lane RETURN by 25%; raised fan labels as well. Moved VOID toward each border (0.055 m inset instead of 0.10 m), inside the small circle instead of crossing it. Shared renderer and regenerated minigame include these positions.
- Added distance gain 1 / (1 + 2.2 d²) relative to the selected mic position. At one metre gain is .3125; at two metres .102 (about -20 dB). Contacts, throws, losses, returns and sliding hiss use it; the end chime remains non-positional. Stereo hiss weighting follows audible contribution.

## Validation

Passed: fx-smoke (including three listener placements, opt-in lamps and actual event output gain), client-smoke, minigame-smoke, settings-revive, determinism, generated bundle check, git diff --check.

Rendered all six glass theme/schema combinations to ignored experiments/logs/revision; inspected kerot/classic composition.

The existing --tone diagnostic still fails its newer dark-room budgets: restored reference floor gives kerot +11.8 floor / +9.9 frame luma versus plain; classic disk +12.8 exceeds its +12 budget. Those budgets target the superseded darker floor, not the requested reference appearance. They were not loosened to hide the mismatch. Physics and scoring are unchanged.
