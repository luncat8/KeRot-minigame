# 0.1.0 worklog — rotating disk curling, implemented

Implemented `archive/0.1.0-plan.md` in full (§12 order), with three plan improvements
found during implementation (folded back into the plan text):

1. Locked pucks advance by exact rotation about the disk centre (a tangent step
   grows the radius every step and slowly self-ejects a held puck).
2. Sleep is gated on |v − v_surf| only where the puck touches the disk; v_surf is
   defined over the whole plane, so the original test meant floor pucks never slept.
3. The lock-band gate is now two series: co-rotating placement (the 90% rule proper,
   locks ≲0.85R, never ≥0.95R) vs lab-rest drop (capture band shrinks to ≈0.5R from
   spin-up drift — real physics, not a bug). Determinism gate compares frame
   batchings at fixed h (bit-identical), not different h values.

Also fixed during validation: pair/spawn positional separation now clamps inside
the walls (it could shove a puck through a wall — caught by tunneling-fuzz trial 1443).
