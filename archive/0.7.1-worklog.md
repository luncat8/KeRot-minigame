# 0.7.1 worklog — Editor copy choices, edit-mode help lock, not-so-big-disk preset

## Review

- Reviewed the 0.7.0 editor work: its next-step note asked for exactly this — testing
  copied custom boards in seeded bot leagues and registering the good ones as named
  presets. The `notsobigdisk` preset below is the first board registered that way (a
  seeded bot league on it completes a full game, see Validation).
- User-requested editor improvements: keep the help drawer and its edge hover out of
  edit mode, and add a second copy button that skips the shipped default values so a
  shared link points at the changes only.

## Implementation

- **Edit mode locks the help** (`js/help.js`, `js/zone-editor.js`): `Help` gains
  `suspend()`/`resume()`. While suspended the drawer stays shut and the edge hover,
  the tab pin, the tap-out dismiss and Escape all ignore it. The editor calls
  `suspend()` on open and `resume()` on close (state restored: a pinned drawer comes
  back). The editor's inert list already covered the panel, menu and help nodes.
- **Two copy buttons** (`js/zone-editor.js`, `js/ui.js`): the drawer's copy row now has
  **Copy preset** (the full descriptor, unchanged) and **Copy changes only**, which
  copies `index.html?` + the keys that differ from the shipped board via the new
  `UI.changesQuery()` (the live link builder). With nothing changed it copies the
  plain `index.html` and says so.
- **`diskScale` enters the live link** (`js/ui.js`): `liveQuery()` echoed every
  difference except `diskScale`, so a board with the scale switch on would have
  copied a link that silently drops it. `SHIPPED.diskScale` and the echo were added —
  the changes link now round-trips the switch.
- **`notsobigdisk` preset** (`js/presets.js`): the wide small-disk board from the
  request — board 4.194 × 2.2 m, disk r = 0.2 at (1.118, 1.1) with `diskScale`, puck
  r = 0.0803, wells r = 0.467 in the far corners, 3-rounded zones, ω = 1.566 (the
  auto-ω of this disk), seats random/balanced/blackhole/retriever. Values are the
  exact board JSON, so the preset reproduces the board bit-for-bit.

## Validation

  `well` / `diskScale` set, ω within 1e-6 of the board's auto-ω, and

  the `diskScale` feature); the rebuild picks up that drift — the bundle now matches
  the sources. `ui.js`/`help.js`/`presets.js` are not part of the minigame bundle.
