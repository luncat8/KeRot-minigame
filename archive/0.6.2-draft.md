# 0.6.2 draft — free-floating scratches, worn hex decor, a stereo listener

User prompt for this round:

```
make big disk's radial decor lines random length and position (not all  start or end
at rim or center). add  in settings instead of it - hex decor, also not sharp with
some randomly  missing edges.

continue with sound:

mic head is in big disk center. stereo pan sounds around it.

settings

- direction faced to: from big disk center to initial puck position | to up |
  from bottom of the canvas below center of  big dis faced to up

- volume. default make 1.3x more then current.
```

Reading:

- The radial brush in `bakeDiskTex` (js/fx-glass.js) currently spans centre→rim on
  every line. Each line gets a free angle, a free start radius and a free length, so
  most touch neither the centre nor the rim.
- A new presentation setting, **disk decor**: the radial brush (default) or a worn
  honeycomb — hex cells baked small and upscaled (soft, never vector-sharp) with
  some edges randomly missing. It replaces the radial lines, not the whole sprite.
- The sound layer gains a listener: the mic head sits on the big disk's centre and
  every positional sound (contacts, rail taps, throws, voids, recycling, the ice
  hiss) pans to where it happened. A **listener** setting picks the facing:
  centre → launch lane (the initial puck position), centre → up, or from the bottom
  edge below the centre, facing up.
- A **volume** slider scales the master gain; the shipped default is 1.3× the old
  fixed level (0.32 → 0.416 effective).
- All three are page state with URL keys (`decor`, `face`, `vol`), like `fx`/`sfx`.
