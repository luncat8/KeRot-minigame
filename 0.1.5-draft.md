# 0.1.5 draft — the straddle wind-up, a handoff timer, and the stray zone ring

User prompt for this round:

```
issues still not fixed: i marked with red cross on err.webp

- case disc partially intersected.
- case long contact (need timer to allow next turn in 4 sec even if movement not finished)
- strange zone around big_disk in last mode we dont need.
```

Notes on the three items:

- **partially intersected.** The 0.1.4 worklog claims this was fixed. It was not: that
  build froze a straddling puck on the first slow step (see the `sleeps 0.00 s` row in
  `experiments/logs/straddle-before-after.png`), so the case looked calm for the wrong
  reason. What the user saw on `err.webp` — a puck left on the rim that will not stop —
  is the behaviour of every build before this one, including 0.1.3's counter-example in
  `archive/0.1.4-worklog.md`. This round has to settle it against the continuum, not
  against a gate written from the same model.
- **long contact.** `CFG.maxResolve` (8 s) was both the ghost-re-sim horizon and the
  turn cap, so a puck the disk keeps nudging held the turn for eight seconds. The turn
  must hand over at 4 s even if the board has not settled; what is still moving stays
  on the board and is simulated while the next player aims.
- **strange zone.** A teal dashed ring hugging the big disk, drawn in both return-rule
  modes, plus long stray diagonals across the board in `advance`. Purely a renderer
  bug: the guard circle was stroked in full instead of the wedge's own boundary.

Still in force from earlier drafts: stroke 0…3 m/s with shift precision, ω capped at
4.000 rad/s defaulting to `autoOmega()` (the 90 % rule), pool of 8 + `maxThrows` 48, the
six-sector pucks, the ghost preview, the two return rules and their on-disk exemption.
